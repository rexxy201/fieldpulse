# FieldPulse

  **ISP Field Service Management Platform**

  A production-ready, end-to-end ISP field service and operations management platform.

  ## Tech Stack
  - **Backend**: PHP 8.2 (built-in dev server)
  - **Database**: PostgreSQL via PDO
  - **Frontend**: Bootstrap 5.3, Bootstrap Icons, vanilla JS
  - **Maps**: Leaflet.js + OpenStreetMap
  - **Charts**: Chart.js 4.x

  ## Features
  - Ticket lifecycle management with SLA/MTTR tracking
  - Technician scheduling & GPS field map with auto-dispatch
  - Customer management & self-service portal
  - Installation profiles with stage tracking
  - Role-based access control (8 roles)
  - In-app notification system
  - Analytics dashboard with 30-day trends

  ## Quick Start
  ```bash
  php -S 0.0.0.0:5000 index.php
  ```

  Default login: `admin` / `admin123`
